# Structured User-Testing Protocol

## Participant requirement

Select one adult outside the project group. Prefer someone with experience in inventory, purchasing, supply chain, healthcare operations or analytics. Do not describe the participant as the actual decision-maker unless that is true. Record only a general role; do not include private employer or patient information.

Suggested description: "The participant is a substitute decision-maker with experience in inventory/supply operations but is not an ED inventory manager."

## Test setup

- Use the deployed application with synthetic data only.
- Do not explain every control before the test; first observe what the participant understands.
- Ask the participant to think aloud.
- Record notes, not personal or confidential information.
- Target duration: 15–20 minutes.

## Tasks

1. **Baseline interpretation**
   - Open one KPI model and select an item/date.
   - Ask: "What does the baseline prediction mean?"
   - Record whether the participant distinguishes prediction from actual hindsight outcome.

2. **Explanation interpretation**
   - Ask: "Which factors most influenced this individual prediction?"
   - Ask: "Is this chart about this one prediction or overall model importance?"

3. **Scenario A**
   - Ask the participant to create one plausible demand scenario.
   - They should compare baseline and modified inputs and prediction.

4. **Scenario B**
   - Ask the participant to create one plausible shortage scenario.
   - They should compare baseline and modified probability and identify whether it crosses the screening threshold.

5. **Decision usefulness**
   - Ask: "What decision, if any, could these results inform?"
   - Ask what additional information they would need before ordering or escalating.

6. **Clarity and missing information**
   - Ask what was confusing, unclear, unnecessary or missing.
   - Ask the participant to rate usefulness from 1 (not useful) to 5 (very useful), with a reason.
